Color Correct

Color Correct is an interactive web app for learning photo editing through hands-on lessons and practice. I built eight lessons covering seven adjustment tools, followed by exercises where users match a target image and receive feedback on their edits.

Type
Self-directed project
Role
Solo. Curriculum, interface, image processing, scoring
Stack

Content

Source
01

Interactive lessons

Eight lessons cover seven adjustment tools — exposure, highlights, shadows, contrast, warmth, tint, and saturation — plus a workflow lesson on combining them. JavaScript Canvas applies per-pixel adjustments as each slider moves, so learners can see the effect immediately.

02

Practice and feedback

Four assessment questions ask learners to match a target image using the lesson tools. Scoring compares slider parameters with target values, using the difference divided by a per-tool tolerance; it does not compute visual similarity. Exposure and warmth have wider tolerances. The edit passes when the average score exceeds a threshold.

Each question includes an authored hint about the intended edit. Computed feedback selects the lowest-scoring adjustment and suggests a direction, such as “The image is too cool. Try increasing the warmth.” It does not reveal target values, the size of the gap, or the other adjustment scores.
